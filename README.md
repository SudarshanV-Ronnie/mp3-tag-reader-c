# 🎵 MP3 Tag Reader in C

A lightweight and efficient **MP3 Metadata Reader** developed in **C Programming** to read, parse, and display **ID3v1** and **ID3v2** tags from MP3 audio files.

---

## 📌 Project Overview

This project demonstrates low-level file handling and binary parsing concepts by extracting metadata information directly from MP3 files.

The application reads MP3 tags and displays important song details such as:

* 🎶 Song Title
* 🎤 Artist Name
* 💽 Album
* 📅 Year
* 📝 Comments
* 🎼 Genre

---

## 🚀 Features

✅ Read ID3v1 metadata
✅ Read ID3v2 metadata
✅ Binary file parsing using C
✅ Low-level file handling
✅ Structured frame extraction
✅ Linux compatible project
✅ Simple command-line interface
